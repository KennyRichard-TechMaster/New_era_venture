# New Era Ventures 🚀

**New Era Ventures** is a high-end, dynamic tech platform designed to showcase professional services and project portfolios with a seamless administrative experience. Built with a modern tech stack, it emphasizes performance, modular architecture, and a premium user interface.

## 🛠 Tech Stack

- **Frontend:** React.js with TypeScript
- **Styling:** Tailwind CSS
- **Backend/Database:** Supabase (PostgreSQL)
- **Icons:** Lucide React
- **State Management:** React Hooks & Context API

## ✨ Key Features

- **Dynamic Portfolio:** A responsive team and project showcase featuring touch-optimized "candid vs. headshot" image toggles.
- **Modular Architecture:** Clean, reusable component structures for services, navigation, and portfolio sections.
- **Admin Dashboard:** Enterprise-level administrative dashboard for real-time content management.
- **Responsive Design:** Fully optimized for all device sizes, from desktop monitors to mobile browser safe-areas.
- **Smooth Animations:** Integrated scroll-reveal effects and fluid transitions for a premium feel.
